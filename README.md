ALUMNIQ —

Empowering Futures, Connecting Generations ALUMNIQ is a premium, digital ecosystem designed to bridge the gap between students and alumni. It provides a centralized platform for secure data management, professional networking, mentorship, and career growth. Built with a modern "Glassmorphism" aesthetic, ALUMNIQ ensures that the bond between an institution and its graduates remains strong and productive.

Key Features

Alumni Networking & Directory Verified Database: Access a searchable directory of alumni, categorized by branch, graduation year, and current company. Global Reach: Connect with alumni working across various industries and locations worldwide.
Mentorship Hub Direct Connection: Students can discover alumni who have opted in as mentors. Request System: Seamless "Request Mentorship" workflow allowing students to seek guidance on career paths, higher studies, and industry trends.
Career Opportunities & Job Board Alumni-Led Postings: Alumni can post job openings and internships directly within their network. Instant Applications: Students can view professional requirements, required skills, and apply for roles with a single click.
Event Management Centralized Calendar: Stay updated with annual alumni meets, technical webinars, workshops, and networking dinners. Real-time Updates: Organizers can post events with descriptions, dates, and modes (Online/On-campus).
Personalized Dashboards Role-Based Access: Tailored experiences for Students, Alumni, Faculty, and Admins. Profile Management: Users can update their professional status, current company, role, and location to keep the network data fresh.
Tech Stack

ALUMNIQ is built using the MERN-lite stack (MongoDB, Express, Node.js) with a high-performance Vanilla JS frontend: Frontend: HTML5, CSS3 (Custom Design System), JavaScript (ES6+). Backend: Node.js, Express.js. Database: MongoDB Atlas (NoSQL) with Mongoose ODM. Security: Password hashing using BcryptJS and role-based access control. Design: Premium Glassmorphism UI, Google Fonts (Outfit & Inter), and responsive CSS Grid/Flexbox layouts.
